# 🎬 Movie Recommender

Веб-приложение для персонализированных рекомендаций фильмов на основе машинного обучения (k-NN, фильтрация по жанрам)

[![Python](https://img.shields.io/badge/Python-3.8+-blue)](https://www.python.org/)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.95+-green)](https://fastapi.tiangolo.com/)
[![PostgreSQL](https://img.shields.io/badge/PostgreSQL-17-blue)](https://www.postgresql.org/)
[![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-yellow)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

## ✨ Функциональность

- 🔍 **Рекомендации по выбранным жанрам** (с сортировкой по рейтингу/популярности)
- 👤 **Рекомендации по профилю пользователя** (пол, возраст, профессия) через k-NN
- 🔐 **Регистрация и вход пользователей** (хеширование паролей pbkdf2_sha256)
- ⭐ **Оценка фильмов** (1-5) с сохранением в профиль
- 🚫 **Автоматическое исключение оценённых фильмов** из новых рекомендаций
- 📋 **Страница "Мои оценки"** с историей и датами
- 🔄 **Дополнение рекомендаций до 10 фильмов**, если часть уже оценена

## 🚀 Запуск проекта

1. **Установка зависимостей**:
```bash
pip install -r requirements.txt
```

2. **Настройка базы данных**:
```bash
python setup_database.py
```

3. **Запуск приложения**:
```bash
uvicorn back.main:app --reload
```

4. **Доступ к приложению**:
Откройте в браузере: http://127.0.0.1:8000

## 📚 Документация API

- `GET /api/genres` - Список доступных жанров
- `GET /api/recommend/genre` - Рекомендации по жанрам
- `POST /api/recommend/profile` - Рекомендации по профилю
- `POST /api/register` - Регистрация пользователя
- `POST /api/login` - Вход пользователя
- `POST /api/rate` - Оценка фильма
- `GET /api/users/{user_id}/ratings` - Оценки пользователя

## 📝 Информация о реализации

### Новые функции реализованы:
1. **Регистрация и вход пользователей** с хешированием паролей
2. **Новые таблицы в БД**:
   - `registered_users` - таблица зарегистрированных пользователей
   - `user_ratings` - таблица оценок пользователей
3. **Хеширование паролей** с использованием passlib[bcrypt]
4. **Визуальный переключатель** между входом и регистрацией на главной странице
5. **Сохранение сессии** пользователей через localStorage

### Технические детали:
- Все старые функции сохранены и работают корректно
- Новые таблицы создаются автоматически при запуске приложения
- Логика обработки оценок пользователей полностью сохранена
- Система предотвращает повторное отображение фильмов, которые уже оценены пользователем

## 📖 Примечания

- Проект использует набор данных MovieLens 100K
- Система рекомендаций основана на алгоритмах машинного обучения k-NN
- Вся информация о пользователях сохраняется в PostgreSQL базе данных с полной аутентификацией
