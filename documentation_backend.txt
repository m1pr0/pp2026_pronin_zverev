ОПИСАНИЕ
--------
FastAPI-сервис рекомендательной системы фильмов.
Два способа получения рекомендаций:
  1) По жанрам — фильтрация фильмов по выбранным жанрам
  2) По профилю — алгоритм k-NN для поиска похожих пользователей

Стек: FastAPI + SQLAlchemy + PostgreSQL
Алгоритм: k-Nearest Neighbors (k-NN) с взвешенной похожестью

================================================================================
                         СТРУКТУРА ФАЙЛОВ
================================================================================

back/
├── __init__.py                        — Инициализация пакета

├── models.py                          — ORM-модели (User, Movie, Rating)
├── genre_recommendation_service.py    — Сервис рекомендаций по жанрам
├── profile_recommendation_service.py  — Сервис рекомендаций по профилю (k-NN)
└── main.py                            — FastAPI приложение + endpoints

================================================================================
                         ЗАПУСК СЕРВЕРА
================================================================================

1. Откройте командную строку (cmd)

2. Перейдите в директорию проекта:
   cd c:\Users\admin\Desktop\PP2026

3. Активируйте виртуальное окружение:
   venvpp\Scripts\activate

4. Запустите сервер:
   uvicorn back.main:app --reload --host 127.0.0.1 --port 8000

   Параметры:
     --reload  — автоматическая перезагрузка при изменении кода
     --host    — адрес (127.0.0.1 = только локальный доступ)
     --port    — порт (по умолчанию 8000)

5. Сервер запущен! Документация:
   http://127.0.0.1:8000/docs  — Swagger UI (интерактивная)
   http://127.0.0.1:8000/redoc — ReDoc (альтернативная)

6. Для остановки: нажмите Ctrl+C или:
   taskkill /F /T /PID <PID_сервера>

5. POST /api/recommend/profile — Рекомендации по профилю
--------------------------------------------------------------------------------
Описание: Персонализированные рекомендации по профилю (пол, возраст, професса).

Параметры (JSON Body):
  gender              — пол (true = Male, false = Female)

================================================================================
                    АЛГОРИТМ K-NN (ПРОФИЛЬ)
================================================================================

1. Сервер получает профиль: пол, возраст, професса
2. Загружаются все пользователи из БД
3. Для каждого вычисляется похожесть:
     - Совпадение по полу: 20% веса
     - Близость по возрасту: 30% веса (нормализация по 50 лет)
     - Совпадение по профессии: 50% веса
   Итог: от 0 до 1
4. Выбираются top_k похожих пользователей
5. Агрегируются их оценки (вес = похожесть)
6. Фильмы сортируются по прогнозируемой оценке
7. Возвращаются top_n рекомендаций

Коды профессий:
  0=academic/educator    1=artist              2=clerical/admin
  3=college student      4=customer service    5=doctor/health care
  6=executive/managerial 7=farmer              8=homemaker
  9=journalist           10=lawyer             11=programmer
  12=retired             13=sales/marketing    14=scientist
  15=self-employed       16=technician/engineer 17=tradesman/craftsman
  18=unemployed          19=writer             21=other
