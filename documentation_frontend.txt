                    FRONTEND — ДОКУМЕНТАЦИЯ
================================================================================

ОПИСАНИЕ
--------
Одностраничное веб-приложение для рекомендательного сервиса фильмов.
Две основные страницы: рекомендация по жанрам и по профилю пользователя.

Стек: HTML + CSS + JavaScript (без фреймворков)
Дизайн: Тёмная тема в стиле Netflix
Адаптивность: Работает на десктопе и мобильных устройствах

================================================================================
                         СТРУКТУРА ФАЙЛОВ
================================================================================

front/
├── index.html     — Главная страница с описанием двух функций
├── genre.html     — Страница рекомендации по жанрам
├── profile.html   — Страница рекомендации по профилю (анкета)
├── style.css      — Общие стили (тёмная тема, адаптивность)
└── script.js      — Логика: запросы к API, отображение фильмов

================================================================================
                    ОПИСАНИЕ СТРАНИЦ
================================================================================

--------------------------------------------------------------------------------
1. index.html — Главная страница
--------------------------------------------------------------------------------
Содержимое:
  - Заголовок и описание сервиса
  - Две карточки функций с иконками:
      🎭 Рекомендация по жанрам
      👤 Рекомендация по профилю
  - Секция "Как это работает" (3 шага)
  - Кнопки перехода на страницы функций

Навигация:
  - Кнопка "Перейти к выбору" → genre.html
  - Кнопка "Заполнить анкету" → profile.html

--------------------------------------------------------------------------------
2. genre.html — Рекомендация по жанрам
--------------------------------------------------------------------------------
Элементы страницы:
  - Чекбоксы всех 18 жанров (загружаются автоматически из API)
  - Радиокнопки сортировки:
      ○ По рейтингу (по умолчанию)
      ○ По популярности
  - Выпадающий список количества: 10, 20, 30, 50
  - Кнопка "Найти фильмы"
  - Секция результатов (сетка карточек фильмов)
  - Индикатор загрузки

Как работает:
  1. При загрузке страницы JS запрашивает /api/genres
  2. Пользователь выбирает жанры и нажимает кнопку
  3. JS собирает выбранные жанры и параметры
  4. Делается GET запрос к /api/recommend/genre
  5. Результаты отображаются в виде карточек с постерами

Пример использования:
  ☑ Action  ☑ Drama
  Сортировка: По рейтингу
  Количество: 20
  → [Найти фильмы]

--------------------------------------------------------------------------------
3. profile.html — Рекомендация по профилю
--------------------------------------------------------------------------------
Элементы страницы:
  - Радиокнопки пола:
      ○ Мужской (по умолчанию)
      ○ Женский
  - Поле ввода возраста (по умолчанию 25)
  - Выпадающий список профессии (21 вариант)
  - Выпадающий список количества рекомендаций: 10, 20, 30, 50
  - Кнопка "Получить рекомендации"
  - Секция результатов (сетка карточек фильмов)
  - Индикатор загрузки

Как работает:
  1. Пользователь заполняет анкету
  2. JS собирает данные и делает POST запрос к /api/recommend/profile
  3. Результаты отображаются с прогнозируемым рейтингом

Пример заполнения:
  Пол: Мужской
  Возраст: 25
  Профессия: Учёный (14)
  Рекомендаций: 20
  → [Получить рекомендации]

================================================================================
                    КАРТОЧКА ФИЛЬМА
================================================================================

Каждая карточка фильма содержит:
  ┌─────────────────────┐
  │     ПОСТЕР          │  ← Изображение или заглушка 🎬
  │                     │
  ├─────────────────────┤
  │ Название (год)      │
  │ [Action] [Drama]    │  ← Жанры (теги)
  │ ⭐ 4.5  150 оценок  │  ← Рейтинг
  └─────────────────────┘

На странице профиля вместо ⭐ показывается:
  🎯 Прогноз: 4.7

При отсутствии постера — заглушка с эмодзи 🎬
При ошибке загрузки изображения — автоматическая замена на заглушку

================================================================================
                    СТИЛИ (style.css)
================================================================================

Цветовая схема:
  Фон основной:    #141414 (чёрный)
  Фон карточек:    #1f1f1f (тёмно-серый)
  Фон форм:        #2a2a2a
  Акцент:          #e50914 (красный, как Netflix)
  Текст:           #ffffff
  Текст вторичный: #b3b3b3

Адаптивность:
  - Десктоп: сетка 4+ карточек в ряд
  - Планшет: 2-3 карточки
  - Мобильный: 1-2 карточки, формы в одну колонку

Анимации:
  - Hover-эффект на карточках (подъём + тень)
  - Плавная смена цветов кнопок
  - Спиннер загрузки

================================================================================
                    JAVASCRIPT (script.js)
================================================================================

Функции:

loadGenres()
  → Загружает жанры из /api/genres
  → Создаёт чекбоксы на странице genre.html

handleGenreSearch(event)
  → Собирает выбранные жанры
  → Делает GET /api/recommend/genre
  → Отображает результаты

handleProfileSearch(event)
  → Собирает данные анкеты
  → Делает POST /api/recommend/profile
  → Отображает результаты

displayMovies(movies, type)
  → Создаёт карточки фильмов
  → type: "genre" (⭐ рейтинг) или "profile" (🎯 прогноз)

Вспомогательные:
  showLoading(show)   — показать/скрыть спиннер
  showResults()       — показать секцию результатов
  hideResults()       — скрыть результаты
  showError(message)  — показать ошибку
  showNoResults()     — сообщение "ничего не найдено"

================================================================================
                    КОНФИГУРАЦИЯ API

В script.js указана базовая строка:
  const API_BASE_URL = "http://127.0.0.1:8000";

================================================================================
                    ВОЗМОЖНЫЕ ПРОБЛЕМЫ
================================================================================

Фильмы не загружаются:
  → Убедитесь, что бэкенд запущен (http://127.0.0.1:8000/api/health)
  → Откройте консоль браузера (F12) → вкладка Console для ошибок

Жанры не отображаются:
  → Проверьте, что БД заполнена данными
  → Запустите: python setup_database.py

Картинки постеров не грузятся:
  → Проверьте интернет-соединение (постеры с TMDB)
  → Скрипт автоматически показывает заглушку при ошибке

CORS ошибка в консоли:
  → Открывайте файл через браузер (file://), не через сервер
  → Или добавьте CORS middleware в FastAPI
