ОПИСАНИЕ
--------
PostgreSQL база данных для хранении информации о фильмах, пользователях
и их оценках. Данные импортированы из датасета MovieLens.

Объём данных:
  🎬 Фильмы:    3 708
  👥 Пользователи: 6 042
  ⭐ Оценки:    ~250 000

================================================================================
                         СТРУКТУРА БАЗЫ ДАННЫХ
================================================================================

Таблица: movies (Фильмы)
-------------------------
Колонки:
  movie_id        INTEGER PRIMARY KEY    — Уникальный ID фильма
  movie_title     TEXT NOT NULL          — Название (с годом выпуска)
  movie_genres    TEXT                   — Коды жанров через запятую ("0, 7")
  poster_url      TEXT                   — Ссылка на постер (TMDB)

Пример данных:
  movie_id | movie_title        | movie_genres | poster_url
  ---------+--------------------+--------------+---------------------------
  3107     | Backdraft (1991)   | 0, 7         | https://image.tmdb.org/...
  2114     | Outsiders, The     | 7            | https://image.tmdb.org/...


Таблица: users (Пользователи)
------------------------------
Колонки:
  user_id                INTEGER PRIMARY KEY  — Уникальный ID пользователя
  user_gender            BOOLEAN              — Пол (True=Male, False=Female)
  bucketized_user_age    INTEGER              — Возраст
  user_occupation_label  INTEGER              — Код профессии (0-21)
  user_occupation_text   TEXT                 — Название профессии
  user_zip_code          VARCHAR(10)          — Почтовый индекс

Пример данных:
  user_id | user_gender | bucketized_user_age | user_occupation_label | user_occupation_text
  --------+-------------+---------------------+----------------------+---------------------
  130     | True        | 35                  | 18                   | technician/engineer
  3829    | False       | 25                  | 0                    | academic/educator


Таблица: ratings (Оценки)
--------------------------
Колонки:
  user_id     INTEGER REFERENCES users(user_id)   — ID пользователя
  movie_id    INTEGER REFERENCES movies(movie_id) — ID фильма
  user_rating FLOAT                               — Оценка (1.0-5.0)
  timestamp   INTEGER                             — Unix timestamp
  PRIMARY KEY (user_id, movie_id)

Пример данных:
  user_id | movie_id | user_rating | timestamp
  --------+----------+-------------+-----------
  130     | 3107     | 5.0         | 977432193
  3829    | 2114     | 4.0         | 965932967

Индексы:
  idx_ratings_movie  — по movie_id (быстрый поиск оценок фильма)
  idx_ratings_user   — по user_id (быстрый поиск оценок пользователя)
  idx_ratings_rating — по user_rating (быстрая фильтрация по оценке)

Стандартная кодировка MovieLens (хранится в back/genres.py):

  0  = Action          6  = Documentary     12 = Mystery
  1  = Adventure       7  = Drama           13 = Romance
  2  = Animation       8  = Fantasy         14 = Sci-Fi
  3  = Children's      9  = Film-Noir       15 = Thriller
  4  = Comedy          10 = Horror          16 = War
  5  = Crime           11 = Musical         17 = Western

Пример: "0, 7" → Action + Drama

================================================================================
                    SQL ЗАПРОСЫ (ПРИМЕРЫ)
================================================================================

Получить топ фильмов по рейтингу:
  SELECT m.movie_title, AVG(r.user_rating) as avg_rating
  FROM movies m
  JOIN ratings r ON m.movie_id = r.movie_id
  GROUP BY m.movie_id, m.movie_title
  ORDER BY avg_rating DESC
  LIMIT 10;

Получить жанры конкретного фильма:
  SELECT movie_genres FROM movies WHERE movie_id = 3107;

Найти пользователей с той же профессией:
  SELECT user_id, user_age FROM users
  WHERE user_occupation_label = 14
  LIMIT 10;

Количество оценок пользователя:
  SELECT COUNT(*) FROM ratings WHERE user_id = 130;

Средний рейтинг фильма:
  SELECT AVG(user_rating) FROM ratings WHERE movie_id = 3107;

================================================================================
                    ОБНОВЛЕНИЕ ДАННЫХ
================================================================================

Для повторного импорта (очистка + загрузка):
  1. Запустите setup_database.py (он удалит старые таблицы)
  2. Или вручную:
     DROP TABLE ratings, users, movies CASCADE;
     Затем запустите импорт

Для обновления connection pool:
  Измените параметры в back/database.py:
    engine = create_engine(DATABASE_URL, pool_size=20, max_overflow=40)

================================================================================
                    ВОЗМОЖНЫЕ ОШИБКИ
================================================================================

База данных не существует:
  → python setup_database.py

Ошибка подключения:
  → Проверьте, что PostgreSQL запущен
  → Проверьте пароль в setup_database.py и .env

Таблицы пусты:
  → Проверьте пути к CSV файлам в setup_database.py
  → Убедитесь, что dataset/movies.csv, users.csv, ratings.csv существуют

Ошибка FOREIGN KEY при импорте:
  → Сначала импортируются movies и users, затем ratings
  → setup_database.py делает это в правильном порядке

Дубликаты при повторном импорте:
  → setup_database.py удаляет таблицы перед созданием
  → Или вручную: DELETE FROM ratings; DELETE FROM movies; DELETE FROM users;
