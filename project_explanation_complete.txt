# Описание проекта Movie Recommender

## Общее описание
Это веб-приложение для рекомендации фильмов, использующее алгоритмы машинного обучения для анализа предпочтений пользователей и предложений персонализированных рекомендаций.

## Структура проекта
Проект разбит на две основные части:
1. Бэкенд (Python/FastAPI) - серверная часть с API
2. Фронтенд (HTML/CSS/JavaScript) - клиентская часть

### Бэкенд (back/)
- **main.py** - основной файл FastAPI приложения с API endpoint'ами
- **database.py** - конфигурация подключения к PostgreSQL
- **models.py** - ORM модели для таблиц БД (фильмы, пользователи, оценки)
- **genre_recommendation_service.py** - сервис рекомендаций по жанрам
- **profile_recommendation_service.py** - сервис рекомендаций по профилю пользователя
- **genres.py** - работа с кодированием/декодированием жанров

### Фронтенд (front/)
- **index.html** - главная страница с описанием сервиса
- **genre.html** - страница рекомендаций по жанрам
- **profile.html** - страница рекомендаций по профилю
- **script.js** - логика JavaScript для взаимодействия с API
- **style.css** - стили страниц

### Данные (dataset/)
- **movies.csv** - информация о фильмах (ID, название, жанры)
- **users.csv** - информация о пользователях (ID, пол, возраст, профессия)
- **ratings.csv** - оценки пользователей фильмам

## Функциональность

### 1. Рекомендации по жанрам
- Пользователь выбирает один или несколько жанров
- Система отфильтровывает фильмы по выбранным жанрам
- Результаты сортируются по рейтингу или популярности
- Пользователь может задать количество фильмов для отображения

### 2. Рекомендации по профилю пользователя
- Пользователь заполняет короткую анкету (пол, возраст, профессия)
- Система находит похожих пользователей по заданному профилю
- На основе оценок похожих пользователей строятся рекомендации
- Для каждой рекомендации выводится прогнозируемая оценка и рейтинг рекомендации

## Архитектура

### Бэкенд (FastAPI)
- Основной API:
  - GET /api/genres - получение списка всех жанров
  - GET /api/recommend/genre - рекомендации по выбранным жанрам
  - POST /api/recommend/profile - рекомендации по профилю пользователя
  - GET /api/health - проверка работоспособности API

### База данных (PostgreSQL)
- Таблицы:
  - movies - информация о фильмах
  - users - информация о пользователях
  - ratings - оценки пользователей фильмам

### Фронтенд (HTML/CSS/JavaScript)
- Динамическое взаимодействие с API
- Формы для ввода параметров рекомендаций
- Отображение результатов с постерами и информацией о фильмах

## Обработка запросов

### Рекомендации по жанрам (GET /api/recommend/genre)
1. Получает список выбранных жанров
2. Использует коды жанров для поиска фильмов
3. Сортирует фильмы по рейтингу или популярности
4. Возвращает список фильмов с информацией о жанрах и оценках

### Рекомендации по профилю (POST /api/recommend/profile)
1. Получает параметры профиля пользователя (пол, возраст, профессия)
2. Находит похожих пользователей с использованием взвешенного метода сравнения
3. Агрегирует оценки похожих пользователей
4. Рассчитывает прогнозируемую оценку для каждого фильма
5. Возвращает отсортированный список рекомендаций

## Установка и запуск

### Требования:
- PostgreSQL 17
- Python 3.8+
- Установленные зависимости из requirements.txt

### Пошаговый запуск:
1. Запустить службу PostgreSQL
2. Установить зависимости: pip install -r requirements.txt
3. Настроить базу данных: python setup_database.py
4. Запустить бэкенд: uvicorn back.main:app --reload --host 127.0.0.1 --port 8000
5. Открыть фронтенд: front/index.html

## Основные алгоритмы

### 1. Поиск по жанрам
- Использует LIKE-запросы в БД для поиска по кодам жанров
- Поддерживает множественный выбор жанров
- Сортировка по среднему рейтингу или количеству оценок

### 2. Рекомендации по профилю
- Алгоритм k-ближайших соседей (k-NN)
- Метрика схожести: взвешенная сумма по полу, возрасту и профессии
- Прогнозирование оценок: взвешенное среднее оценок похожих пользователей

## Технические детали

### Формат данных жанров
- Жанры кодируются в числовые ID (0-17)
- Прямой маппинг: 0="Action", 1="Adventure", ... , 17="Western"
- Жанры хранятся в БД в виде строки кодов через запятую: "0, 7"

### REST API
- Все API вызовы возвращают JSON
- Все API endpoint'ы документированы
- Используется CORS для разработки

### Безопасность
- Проверка подлинности не требуется (локальная разработка)
- Установлены CORS правила для разработки

## Назначение файлов проекта

### Бэкенд (back/)
- **main.py** - основной файл FastAPI приложения с API endpoint'ами. Определяет все API маршруты и логику взаимодействия с базой данных.
- **database.py** - реализует конфигурацию подключения к PostgreSQL базе данных. Содержит настройки подключения и фабрику сессий.
- **models.py** - определяет ORM модели для таблиц базы данных: фильмы (movies), пользователи (users) и оценки (ratings).
- **genre_recommendation_service.py** - сервис, реализующий логику рекомендаций фильмов по жанрам. Содержит функции для фильтрации фильмов и сортировки по различным критериям.
- **profile_recommendation_service.py** - сервис рекомендаций по профилю пользователя. Реализует алгоритм k-ближайших соседей для поиска похожих пользователей и формирования персонализированных рекомендаций.
- **genres.py** - вспомогательный модуль для работы с кодами жанров, включая кодирование/декодирование и предоставление полного списка жанров.

### Фронтенд (front/)
- **index.html** - главная страница пользовательского интерфейса. Представляет общую информацию о сервисе и содержит ссылки на функциональность.
- **genre.html** - страница для рекомендаций по жанрам. Содержит форму выбора жанров и отображение результатов.
- **profile.html** - страница для рекомендаций по профилю пользователя. Предоставляет форму для ввода данных пользователя и отображает рекомендации.
- **script.js** - JavaScript логика взаимодействия с API. Обрабатывает формы, отправляет запросы к бэкенду и отображает результаты.
- **style.css** - CSS стили для оформления пользовательского интерфейса. Определяет внешний вид всех элементов страниц.

### Скрипты и данные
- **setup_database.py** - скрипт автоматической настройки базы данных и импорта данных из CSV файлов.
- **test_services.py** - файл с тестами для проверки работы сервисов рекомендаций.
- **requirements.txt** - список зависимостей Python для установки через pip.
- **HOW_TO_RUN.txt** - подробная инструкция по запуску проекта с описанием шагов и команд.
- **README.md** - краткое описание проекта и его цели.
- **dataset/** - папка с CSV файлами данных (movies.csv, users.csv, ratings.csv) для симуляции реальных данных.
- **.gitignore** - файл, определяющий, какие файлы Git должен игнорировать при отслеживании изменений.
