# ПОЛНОЕ ОБЪЯСНЕНИЕ РАБОТЫ ПРОЕКТА MOVIE RECOMMENDER

## ОБЩЕЕ ОПИСАНИЕ
Movie Recommender - веб-приложение для персонализированных рекомендаций фильмов на основе машинного обучения. Приложение предоставляет рекомендации по жанрам и пользовательскому профилю, позволяет пользователям регистрироваться, оценивать фильмы и просматривать свою историю оценок.

## ДЕТАЛЬНОЕ ОПИСАНИЕ КАЖДОГО ФАЙЛА

### 1. ОСНОВНОЙ ФАЙЛ БЭКЕНДА: back/main.py
Основной файл приложения с FastAPI. Содержит все API эндпоинты:
- /api/genres - получение списка жанров
- /api/recommend/genre - рекомендации по жанрам
- /api/recommend/profile - рекомендации по профилю
- /api/register - регистрация пользователя
- /api/login - вход пользователя
- /api/rate - оценка фильма
- /api/users/{user_id}/ratings - получение оценок пользователя
- /api/health - проверка работоспособности API

### 2. БАЗА ДАННЫХ: back/database.py
Подключается к PostgreSQL и создает таблицы:
- Создает engine и sessionmaker
- Выполняет Base.metadata.create_all() для инициализации таблиц
- Реализует функцию get_db для получения сессий БД

### 3. МОДЕЛИ ДАННЫХ: back/models.py
ORM модели SQLAlchemy для работы с БД:
- User - пользователь (старая модель)
- Movie - фильм (старая модель)
- Rating - оценка (старая модель)
- RegisteredUser - новый пользователь (новая модель)
- UserRating - оценки пользователей (новая модель)

### 4. БЕЗОПАСНОСТЬ: back/security.py
Функции для работы с паролями:
- hash_password(password: str) -> str - хеширование пароля с использованием bcrypt
- verify_password(plain_password: str, hashed_password: str) -> bool - проверка пароля

### 5. ИНИЦИАЛИЗАЦИЯ ТАБЛИЦ: back/init_new_tables.py
Скрипт для инициализации новых таблиц. Выполняет:
- Импорт Base из models.py
- Создание таблиц зарегистрированных пользователей и их оценок

### 6. СЕРВИСЫ РЕКОМЕНДАЦИЙ:
- genre_recommendation_service.py - сервис для получения рекомендаций по жанрам
- profile_recommendation_service.py - сервис для получения рекомендаций по профилю

## ФУНКЦИОНАЛЬНОСТЬ ПРОЕКТА

### 1. РЕКОМЕНДАЦИИ ПО ЖАНРАМ
- Пользователь выбирает один или несколько жанров
- Указывается максимальное количество фильмов
- Выбирается сортировка (рейтинг или популярность)
- Получаются фильмы с минимальным рейтингом 2.5

### 2. РЕКОМЕНДАЦИИ ПО ПРОФИЛЮ
- Пользователь заполняет анкету (пол, возраст, профессия)
- Алгоритм k-NN находит похожих пользователей
- На основе профилей аналогичных пользователей строятся рекомендации
- Фильмы с прогнозируемой оценкой выше 2.5

### 3. АУТЕНТИФИКАЦИЯ ПОЛЬЗОВАТЕЛЕЙ
- Регистрация новых пользователей с хешированием паролей
- Вход по имени пользователя и паролю
- Сохранение сессии через localStorage
- Визуальный переключатель между входом и регистрацией

### 4. ОЦЕНИВАНИЕ ФИЛЬМОВ
- Пользователь может оценить фильмы от 1 до 5 звезд
- Оценки сохраняются в базе данных
- Автоматическое исключение уже оцененных фильмов из рекомендаций

### 5. ИСТОРИЯ ОЦЕНОК
- Страница "Мои оценки" отображает все оцененные фильмы
- Показываются даты и время оценки
- История сохраняется для каждого пользователя отдельно

## ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ

### Технологии:
- Бэкенд: Python 3.8+, FastAPI, SQLAlchemy
- База данных: PostgreSQL 17
- Фронтенд: HTML5, CSS3, Vanilla JavaScript
- Алгоритмы: k-NN, взвешенная метрика схожести
- Безопасность: passlib (bcrypt) для хеширования паролей

### ОСНОВНЫЕ ФУНКЦИИ:
1. Работа с большими наборами данных (MovieLens)
2. Рекомендательные алгоритмы машинного обучения
3. Полная аутентификация пользователей
4. Хранение и управление историей оценок
5. Адаптивный пользовательский интерфейс

## ПОРОЯДОК РАБОТЫ ПРИЛОЖЕНИЯ

1. Пользователь запускает приложение через FastAPI сервер
2. Приложение запускает все API эндпоинты
3. Пользователь видит главную страницу с формой входа/регистрации
4. При входе/регистрации пользователь получает session ID
5. Пользователь переходит на страницы рекомендаций
6. При выборе рекомендаций происходит обращение к API
7. Рекомендации возвращаются и отображаются на фронтенде
8. Пользователь может оценивать фильмы
9. Оценки сохраняются в базу данных

## ВЗАИМОДЕЙСТВИЕ КОМПОНЕНТОВ

### API ВЗАИМОДЕЙСТВИЕ:
- Фронтенд обращается к FastAPI endpoints
- FastAPI взаимодействует с базой данных через SQLAlchemy ORM
- Сервисы рекомендаций используют данные из базы для анализа
- Взаимодействие через JSON формат

### ПРОЦЕСС АУТЕНТИФИКАЦИИ:
1. Пользователь регистрируется/входит через форму
2. Данные передаются на /api/register или /api/login
3. Система хеширует пароль (security.py)
4. Пользователь сохраняется в RegisteredUser таблице
5. Session ID сохраняется в localStorage

### ПРОЦЕСС ОЦЕНИВАНИЯ ФИЛЬМОВ:
1. Пользователь выбирает фильм и ставит оценку
2. Запрос отправляется на /api/rate
3. Оценка сохраняется в UserRating таблицу
4. При следующих рекомендациях исключаются уже оцененные фильмы

## БАЗА ДАННЫХ

### СТАРЫЕ ТАБЛИЦЫ:
- users: пользователи (User)
- movies: фильмы (Movie)  
- ratings: оценки (Rating)

### НОВЫЕ ТАБЛИЦЫ:
- registered_users: зарегистрированные пользователи (RegisteredUser)
- user_ratings: оценки пользователей (UserRating)

### СВЯЗИ МЕЖДУ ТАБЛИЦАМИ:
- RegisteredUser.id → UserRating.user_id (Foreign Key)
- UserRating.movie_id → Movie.movie_id (Foreign Key)

Все изменения реализованы без потери функциональности старых частей проекта.
